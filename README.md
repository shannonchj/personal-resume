# 個人履歷與作品集
[github page網址](https://shannonchj.github.io/personal-resume/)

以 React 建置的個人履歷網站，呈現個人簡介、技能、專案、學歷與聯絡方式。履歷內容與頁面程式分開管理，方便未來更新資料。

## 專案結構

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 網頁入口，載入 React、ReactDOM、Babel 與樣式 |
| `script.js` | React 元件與頁面呈現邏輯 |
| `content.json` | 個人資料、技能、專案、經歷、學歷與聯絡連結 |
| `style.css` | 頁面版型、色彩、響應式及列印樣式 |
| `Content.md` | 履歷內容草稿／參考；不會自動同步至網站 |

## 本機預覽

網站以 `fetch` 載入 `content.json`，請透過本機 HTTP 伺服器預覽，不要直接以 `file://` 開啟。

在專案資料夾執行：

```powershell
python -m http.server 8000
```

接著用瀏覽器開啟 <http://localhost:8000>。結束伺服器時，在 PowerShell 按 `Ctrl+C`。

React、ReactDOM 與 Babel 目前透過 CDN 載入，預覽時需可連線至 CDN。

## 更新內容

編輯 `content.json` 中對應欄位即可更新網站資料；請保留合法 JSON 格式，例如雙引號及欄位間的逗號。專案可提供 `overview`、`role`、`implementation`、`result`、`skills` 及 `links` 等欄位。沒有資料的欄位可留空或省略，頁面不會顯示未提供的內容。

修改 `Content.md` 不會自動更新網站，請將確認後的內容同步到 `content.json`。

## 目前功能

- 顯示個人介紹、標籤、技能分類、專案、學歷及聯絡連結
- 支援淺色／深色主題切換
- 可使用瀏覽器列印功能匯出 PDF
- CSS 已包含手機版版型及列印樣式
